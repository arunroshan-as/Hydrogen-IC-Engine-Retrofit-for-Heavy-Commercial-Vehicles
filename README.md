Hydrogen IC Engine Retrofit for Heavy Commercial Vehicles

Overview

This project focuses on the research and development of a hydrogen-fueled retrofit system for existing compression-ignition (CI) engines used in heavy commercial vehicles.

The objective is to investigate how hydrogen-based fueling, electronic engine control, and combustion optimization can be integrated with an existing engine architecture while minimizing major mechanical modifications.

Project Objectives

Develop a hydrogen fuel integration concept for existing CI engines

Design a controlled hydrogen fuel delivery system

Develop an electronic control strategy for hydrogen injection

Study hydrogen–air combustion characteristics

Optimize injection and combustion parameters

Evaluate engine performance and efficiency

Investigate emissions reduction potential

Develop a scalable retrofit approach for heavy commercial vehicles

System Concept

The retrofit concept consists of:

Hydrogen Storage → Pressure Regulation → Fuel Delivery → Injection System → Engine → ECU → Sensors & Feedback

The existing engine architecture is retained as far as practical, while the fuel delivery and electronic control systems are adapted for hydrogen operation.

Engine Control

The proposed electronic control system considers parameters such as:

Crankshaft position

Engine speed

Intake manifold pressure

Throttle position

Knock tendency

Engine operating conditions

Hydrogen injection timing

Ignition / combustion timing

An embedded ECU architecture is being investigated for real-time sensing, control and actuation.
